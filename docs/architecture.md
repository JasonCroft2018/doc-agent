## 关键技术决策

### 为什么用 LangGraph 而不是 LangChain Agent？

| 对比 | LangChain AgentExecutor | LangGraph |
|:----|:-----------------------|:----------|
| 状态管理 | 线性链，难以处理复杂分支 | 状态图，支持分支、循环、并行 |
| 可观测性 | 有限的 callback | 原生支持每一步的 state 检查 |
| 灵活性 | 修改流程需要重写 chain | 增删节点即可调整流程 |
| 复杂度 | 简单场景好用，复杂场景受限 | 学习曲线稍高，但上限更高 |

### 为什么用混合检索而不是纯向量检索？

| 场景 | 纯向量检索 | 混合检索（向量 + BM25） |
|:----|:---------|:---------------------|
| "Transformer 注意力" | ✅ 语义匹配好 | ✅ 更好 |
| "QKV 矩阵计算" | ⚠️ 可能漏掉精确匹配 | ✅ BM25 补全精确匹配 |
| "合同编号 CON-2025-038" | ❌ 几乎找不到 | ✅ BM25 精准匹配 |
| 长尾专业术语 | ⚠️ 不稳定 | ✅ 更稳定 |
